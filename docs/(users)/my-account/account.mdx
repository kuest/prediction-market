Open **Settings → Account** for security and deletion controls.

## Two-factor authentication

Two-factor authentication (2FA) uses a six-digit code from an authenticator app.

1. Select **Enable 2FA**.
2. Scan the QR code, open the mobile link, or enter the setup secret manually.
3. Enter the six-digit code generated by the authenticator.
4. Optionally trust the current device for 30 days.

After 2FA is enabled, sign-in may redirect to **/2fa** before access is granted.

<Callout type="warning" title="Save access safely">
  Keep authenticator recovery information in a secure location. Never send a setup secret or one-time code to support.
</Callout>

## Delete your account

Account deletion is permanent. Export any records you need and connect the wallet linked
to your account. Type **DELETE** in the confirmation dialog, then approve the requested
wallet signatures to authorize deletion.

Deletion removes the platform account, sessions, linked wallet records, 2FA setup, order
records, and referral relationships, then signs you out. It does not erase public
blockchain history.
