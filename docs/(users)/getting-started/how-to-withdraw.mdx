---
title: Withdraw Funds
description: Send available USDC to a wallet on Polygon
---

Open **Portfolio → Withdraw** to send available funds to a wallet address.
The current withdrawal flow supports **USDC on Polygon**, not bank withdrawals.

1. Enter the recipient address, or select **use connected** when available.
2. Enter the amount, or choose **Max** to use the available balance.
3. Check the recipient, token, network, and amount before submitting.
4. Approve the wallet request and wait for confirmation.

<Callout type="warning" title="Check the destination">
  Make sure the receiving wallet or exchange accepts the USDC token used by this platform on Polygon.
  Transfers to an incorrect address or unsupported network may be unrecoverable.
</Callout>
